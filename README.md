# ДФК «Спартак» · Снегири

[Открыть сайт](https://egkodin.github.io/spartak-snegiri/)

Самостоятельный сайт футбольного клуба: тренеры, фотографии зала, расписание, стоимость и запись через Telegram, Max или телефон. React, TypeScript и Vite; сервер и секреты не нужны.

## Локальный запуск

Node.js 24:

```sh
npm ci
npm run dev
```

Сборка и проверка:

```sh
npm run build
npm test
npm run preview -- --host 127.0.0.1 --port 4173
```

Браузерная проверка использует установленный Playwright:

```sh
SPARTAK_BASE_URL=http://127.0.0.1:4173/ npm run test:browser
```

Если Playwright установлен вне проекта, задайте `PLAYWRIGHT_PATH` — абсолютный путь к его пакету. Для собственного браузера задайте `SPARTAK_BROWSER` — путь к Chromium/Chrome. Скриншоты сохраняются в системную временную папку `/tmp/spartak-smoke`; каталог можно изменить через `SPARTAK_SCREENSHOTS`. Проверка не отправляет сообщения: Telegram заменён тестовой страницей.

## Файлы и публикация

- `src/App.tsx` — страница; `src/components.tsx` — тренеры, галерея и расписание.
- `src/content.ts` — контакты, группы, цены и фотографии.
- `src/base.css`, `src/spartak.css` — оформление.
- `public/` — только используемые изображения, иконки и файлы индексации.
- `scripts/` — предварительная отрисовка HTML, проверка сборки и браузерный тест.
- `.github/workflows/pages.yml` — автоматическая публикация после push в `main`.

В GitHub Settings → Pages выбран источник **GitHub Actions**. Workflow выполняет `npm ci`, сборку и `npm test`, затем публикует `dist`. Для отката отмените нужный коммит через `git revert` и отправьте новый коммит в `main`.

Контакты и расписание перенесены с [сайта ДФК](https://fc-spartak.tb.ru/snegiri) и [страницы стоимости](https://fc-spartak.tb.ru/timing_snegiri). Биографии тренеров сохранены по данным заказчика. Фотографии зала предоставлены заказчиком и обработаны Imagegen; генеративная реставрация может менять мелкие детали. Иконки [Icons8](https://icons8.com) используются с атрибуцией; каталог и ссылки на условия находятся в `icons8.json`.
