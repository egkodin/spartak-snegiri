# ДФК «Спартак» · Снегири

Сайт детского футбольного клуба: тренеры, расписание, цены и запись на тренировку.

[Открыть сайт](https://egkodin.github.io/spartak-snegiri/)

## Запуск

Нужен Node.js 24.

```sh
npm ci
npm run dev
```

Сборка: `npm run build`. Готовый сайт появится в папке `dist`.

После push в `main` сайт автоматически обновляется на GitHub Pages.

Иконки: [Icons8](https://icons8.com).
